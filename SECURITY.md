# Reporting a security issue

Email support@slithy.io with the subject "Security report". Describe the affected
version, likely impact and reproduction steps using disposable data.

Do not send recovery words, wallet passwords, signing keys or real wallet files.
If the report needs sensitive attachments, ask for a secure transfer method first.
Do not publish exploit details while a report is being investigated.

The project is small and does not promise a fixed response time or a paid bounty.
The current beta release is the supported testing target. Older beta generations
may require migration rather than a patch.

No audit or passing test suite establishes that cryptocurrency software has no
security risks. Use test funds, back up wallets and verify official downloads.
