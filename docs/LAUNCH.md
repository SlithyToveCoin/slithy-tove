# Slithy Tove live launch

The live network launches on **January 1, 2027**. This is the confirmed launch date. The exact start time in UTC will be announced before launch.

The Windows and Linux downloads currently use the public test network. Test coins have no market value. The test chain and balances will reset before the live launch, and testers should expect to create new wallets. Test coins will not convert into live coins.

The launch plan has no premine or private sale. Official project nodes check and relay blocks without mining. The live-network software and start time will be public before mining opens.

## Earlier launch dates

This announcement, updated November 17, 2026, replaces the dates in earlier beta release notes. Existing signed beta downloads are unchanged. The launch date in their bundled terms will be updated in the next regular app release.
