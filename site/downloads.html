Linux desktop beta

Linux wallet and miner

Create a wallet and start mining with the same Home, Activity and Settings tabs as the Windows app. Slithy runs its own local node on your computer.

Download Linux desktop app

Version 0.1.49-beta.1 for Linux x64 desktops. Ubuntu 24.04 is the reference platform; other distributions and desktop environments need testing. Extract the archive into a folder you own, open slithy-install, then choose Install for my account. No sudo or separate .NET installation is needed.

Mining starts with one CPU thread unless you've saved a different count. Click the thread count below the mining button to open Settings > CPU mining. Your choice applies the next time you start mining. The app checks for updates while it's running and shows a badge when one is available. Read the Linux desktop instructions.

Includes the same wallet-request and recovery-error fixes as Windows. It also checks linked settings and update folders before using them. Read about the wallet tools.

Before you test

Read the Terms of Use and Beta Testing. Mining uses electricity and computer resources, and rewards are not guaranteed. Test coins have no market value. Wallets and the test chain will reset before launch.

Updating from the old test chain

The test chain restarted on September 9, 2026. Old test coins do not carry over. Your previous wallet files stay on your computer. The live launch is planned for December 1, 2026, and test balances will reset again before that launch.

Windows: use Check for updates in the app. If version 0.1.35 closes without installing, or version 0.1.37 offers the same update again, exit Slithy through the notification-area menu and run the installer above once. It replaces the app without deleting your wallet files. Create a new beta wallet if prompted. A wallet created with the replacement-beta build, such as version 0.1.36, can still be used.

Linux: download the desktop app above and follow the installation steps. If you used the older terminal app, stop its mining and node before opening the desktop app. Leave its wallet and chain folders in place. The desktop app uses a separate data folder.

Create a new wallet for this test chain. A wallet from before the September reset cannot carry its old balance into the current beta. If you need help stopping an older installation or moving a current-beta wallet, ask in the community before changing files.
