03 / Project facts

What is Slithy Tove?

A short introduction

Slithy Tove is an open-source cryptocurrency project that uses CPU mining to support a public fund for children's literacy. Ten percent of each block's newly created coins goes to the fund. The Windows and Linux apps include a wallet, a local node and a miner.

The project is in public beta. Test coins have no market value and will not carry over to the live network.

Where the fund fits in

The intention is to help pay for books and reading programs. CS Idea Labs LLC publishes the software and will control the treasury wallet at launch. Community voting on spending is planned. It is not available yet.

Why the name?

The name comes from the "slithy toves" in Lewis Carroll's poem Jabberwocky. It connects the project to the imagination and fun that reading can bring.
